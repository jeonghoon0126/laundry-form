# 8월 캐리 정산 기준

## 기준

- 정산 기간: 2026-07-31 ~ 2026-08-30
- 정산 매출: 8,594,450원
- 건조기 비용: 이번 달만 발생한 일회성 지출. 반복 정산비용에서 제외

## 결론

- 총비용: 6,216,884원
- 종소세 적립 전 영업이익: 2,377,566원
- 종소세 적립금: 361,135원
- 건조기 비용을 제외한 세금 적립 후 정산 가능액: **2,016,431원**
- 현재 캐리 통장 잔액: 1,750,000원 (소모품 이체 후)

통장 잔액과 정산 가능액은 지급·이체 시점 차이로 별도 숫자다. 건조기 비용 약 90~100만원은 이미 빠진 일회성 지출이므로 다시 차감하지 않는다.

## 앞으로의 정산 로직

- 고정비와 이체주기는 위 기준을 사용한다.
- 소모품·부가세·종소세는 월별 실제 확인값이 있으면 해당 월 override로 반영한다.
- 실제값이 없는 월은 기존 모델을 사용한다: 소모품은 기준 매출 대비 비율, 부가세는 매출 부가세에서 매입세액공제를 뺀 금액, 종소세는 월 영업이익을 연환산한 누진세액 기준이다.
- 적립금은 신고·납부 확정세액이 아니며, 확정 시 실제값으로 교체한다.

- 인건비: 매월 20일 수기 이체

- 원천세·부가세·종소세: 별도 적립금으로 보관
